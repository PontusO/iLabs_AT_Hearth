# Signing keys

`hearth_dev_p256.pem` is the DEVELOPMENT signing key. It is deliberately
committed: same trust stance as the esp-matter test credentials, it
protects nothing and exists so every dev build is signed and the
verification path is always exercised.

The PRODUCTION key is generated by the maintainer, held outside every
repository, and never committed. At fixture time the production MCUboot
is built with `SB_CONFIG_BOOT_SIGNATURE_KEY_FILE` pointing at it; images
for production devices are signed with it by the release process. A
production module never trusts the dev key.
